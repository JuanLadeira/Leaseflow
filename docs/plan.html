Decisões para defender

RTK Query para dados do servidor

Cache, deduplicação e invalidação por tags. Slices ficam só com estado de UI, como filtros e painel aberto.

Context só para auth e tema

Valores que mudam pouco. Dois contextos separados para que trocar o tema não re-renderize quem só lê o usuário.

Streaming com fetch + ReadableStream

EventSource só faz GET e não manda header de auth. Um POST com leitura do body em chunks resolve os dois.

Django Ninja em vez de DRF

Schemas Pydantic tipados, OpenAPI automático para gerar tipos do front, e views async para o stream.

JWT com access curto

Access em memória, refresh renovado via RTK Query baseQueryWithReauth.
